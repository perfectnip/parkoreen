Embedding Parkoreen

Place the game itself in an iframe on a page hosted at the same origin.

Embed the game root

Use the deployed game URL directly. There is no separate wrapper page:

<iframe
  src="https://perfectnip.github.io/parkoreen/"
  title="Parkoreen"
  width="100%"
  height="720"
  style="border:0"
  allow="fullscreen"
  allowfullscreen>
</iframe>

Adjust the height to fit your page. On small screens, use a responsive height such as min-height: 80vh. The game adapts its controls and layout to the available device and input.

Same-origin requirements

For the parent page and game to share browser storage or communicate with each other, they must have the same scheme, hostname, and port. A page hosted at https://perfectnip.github.io/parkoreen/ can embed the game root at that same origin. A page on a different hostname is cross-origin; the game can still be framed when the host allows it, but browser same-origin storage and direct parent-page access are unavailable.

Parkoreen keeps its internal page navigation inside the iframe. The same-origin game pages can access the same browser storage, including locally saved settings and level progress. Account-backed services still use the game’s configured backend.

Test your embed

  1. Open the parent page from its deployed same-origin URL, not from a file:// path.
  2. Confirm the frame is tall enough for the game and its menus.
  3. Navigate between the home screen, levels, and editor to confirm the frame remains in place.
  4. On touch devices, check that the touch controls are not covered or clipped by the parent page.

Embedding does not expose a supported API for controlling the game from a parent page. For map sharing, hosting, and room codes, see Community Maps and Lobbies.
