Community Maps and Lobbies

Share maps, find a game, and choose how others can use your creation.

Publish a map

Open Community while signed in. Select one of your saved maps, choose one or more existing tags, or enter new comma-separated tags, then publish. New tags are added to the shared list automatically. The built-in tags are Race, Impossible, Easy, Weird, and High Quality. You can choose up to eight tags per map.

Recommendations, ratings, and comments

Suggested maps are ranked using the tags you play most, tags where your ratings are highest, the community’s map ratings, and how recently a map was published. You can switch to Highest rated or Recently published, or filter by tag. Signed-in players can rate each map from one to five stars and add comments.

Downloads and hosting

When publishing, turn on Allow players to download to show a .pkrn download. If it is off, the in-game download control is hidden; players can still host the map from the Community. Hosting sends map data to the browser that runs the room, so the setting controls the supported download feature and cannot prevent a determined player from copying data delivered to their browser.

Public and private rooms

In the editor’s Host Game settings, set visibility to Public or Private. Public rooms appear in Public Lobbies; private rooms are only available to players with their six-character join code. Rooms support up to ten players. Full rooms leave the public list automatically.

Quick Join joins the fullest available public room. Refresh the lobby list if rooms have changed since it loaded.
