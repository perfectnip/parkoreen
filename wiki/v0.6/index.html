Parkoreen — V0.6 Guide

The complete reference for Parkoreen V0.6-Indev, including its game editor, Mechanics system, plugins, AI Map Assistant, and device-adaptive controls.

About this Guide: This is maintained reference documentation. Players can read these pages, but cannot edit them.

V0.6 engine features

  • Mechanics editor: reusable Events, conditions, typed map, cross-map campaign, and per-player variables and Lists, timers, dialogue, menus, inventory flows, checkpoints, object health and movement, temporary object spawning, and room-specific gravity, jump force, speed, acceleration, air control, and terminal fall settings. Campaign state saves locally for solo play and does not sync across devices. Templates include Tag, Hide and Seek, Timed Round, and platformer/RPG building blocks.
  • Triggers: game and room lifecycle, zone and object contact, tilemap contact, buttons, player input, jumps, landings, health changes, attacks, variables, player stats, and timed repetition.
  • 2D world: named parallax draw layers, sparse native tilemaps with custom atlases, one-way ramps, hazards and polygon collision, camera bounds and follow modes, saved-map transitions, and portable Object Stamps.
  • Hollow Knight plugin: directional nail attacks, pogo from solid surfaces and tilemaps with a default rebound height of half a maximum jump, Soul, Focus, Monarch Wings, Mantis Claw (spikes cannot be climbed), dash abilities, and configurable visual effects.
  • Background presets: choose from Sky, Galaxy, Misty Mountains, Pine Forest, Quiet Coast, Desert Dunes, and Twilight Ruins. The editor displays image previews for the presets.
  • Visual colors: the game keeps its original dark blue surfaces with green #007800 and orange #FF7800 as its main accents.
  • Mobile and desktop: editor tools, game controls, settings, and HUD adapt to device capabilities. Hybrid devices can switch between touch and keyboard/mouse input automatically.
  • Same-origin embedding: load embed.html in an iframe on the Parkoreen domain. The frame stays full-screen and keeps game navigation, storage, and level progress in the embedded session.
  • AI Map Assistant: temporarily paused while map-generation quality is improved. Its editor button is hidden and the service does not send requests to OpenAI. Existing conversations remain in each player's browser; community maps are not used for training.
  • Plugin development: the Guide includes a quickstart for the trusted API v1 starter, local preview, validator, and package tools. Community plugin installation remains unavailable until isolation and permissions are implemented.
  • Community: publish tagged maps, collect star ratings and comments, browse personalized suggestions, download maps when allowed, and host maps in public or private rooms.
  • Persistence: maps save locally in the browser and can be exported; saves do not automatically sync across devices.
