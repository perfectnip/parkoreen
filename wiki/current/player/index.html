🧑 Player

Player physics, movement, hitboxes, and respawn logic.

Size

The player sprite is 32×32 px, matching one grid cell.

Physics defaults

PropertyDefault value
Gravity0.71 per tick
Jump force-13.2 (upward)
Move speed5 px/tick
Max jumps1

All values are overridable per-map in Map Config.

Character sprite sheet

In the editor, open Map Config → Player → Character Sprite Sheet to replace the colored player with a map-specific animation. Upload a PNG, JPEG, or WebP sprite sheet (up to 1 MB); the player still uses the same 32×32 collision and name display.

Set the frame width and height, then choose a row, frame count, and playback speed for each state. Frames are read from left to right. The engine selects Idle when grounded and still, Run when grounded and moving, Jump while rising, and Fall while descending. Optionally configure Attack, Hurt, and Dash rows. The default optional row numbers are 4, 5, and 6, so a seven-row sheet can use rows 0–3 for locomotion, followed by Attack, Hurt, and Dash. Plugins activate rows through shared player states: Hollow Knight plays Attack during a nail swing and Dash during Dash or Super Dash, while the Health plugin can play Hurt during its damage-stun window. Attack plays once; Hurt and Dash loop while their state is active. If a state is not configured, locomotion continues to display. The sprite faces the player's last movement direction. Maps keep this configuration when saved and in .pkrn exports.

Jump system

  • Max Jumps — number of jumps allowed before the player must land. Default: 1.
  • Infinite Jumps — when on, the player can jump at any time.
  • Additional Air Jump — grants one bonus jump while airborne (double-jump), spending from Max Jumps.
  • Jumping is triggered with W or Space.

Death & respawn

  • The player dies when the Hurt box overlaps an active hazard, or when they fall below Die Line Y (default 1000 px).
  • On death the player respawns at the active checkpoint, or the map's spawn point if no checkpoint has been touched.

Coins

The player has a coin count. Collecting a Coin object increases their count by the coin's coinAmount. The coin counter HUD is shown when Show Coin Counter is enabled in Map Config.
