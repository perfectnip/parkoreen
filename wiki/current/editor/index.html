Current

🖊 Editor

All editor tools, multi-select, keyboard shortcuts, and workflow in the current version.

Grid & snapping

All objects snap to a 32×32 px grid. Grid lines are visible on the canvas in edit mode.

Object layers

Open Layers to manage named draw layers and assign visual objects to them. The built-in depths remain compatible with existing maps: 0 behind the player, 1 at player depth (drawn just below the player), and 2 above the player. Use the add buttons to create custom layers on either side of the player, then rename or remove them. Custom layers can set separate horizontal and vertical parallax factors from 0 to 2; lower values move scenery more slowly than the camera, and 1 keeps normal camera movement. The editor keeps all layers aligned for precise placement; parallax is applied during Play and Test. Zones and buttons remain visible overlays. Draw layers do not change collision. Layer names, parallax settings, and object assignments survive map save/load and .pkrn export/import.

If a Mechanics action or Python event fails during Test Game, Parkoreen shows a brief error notice with the Event, action, and message. Recent failures remain in the Mechanics dashboard after testing; select an error to reopen its Event. Repeated copies of the same failure are rate-limited so a broken repeating flow does not flood the screen. See the Mechanics guide for trigger types, Event flows, variables, templates, and hosted-room behavior.

If a map contains a trigger or action type from a newer Parkoreen version, an older editor keeps the trigger configuration and linked Event, or the action and its saved fields, while you edit the map. Unknown variable and List item value types also remain intact when you make other edits. You can remove or replace an unsupported record explicitly. An older runtime cannot execute unknown mechanic types; it records an author-facing error until the map is opened in a version that supports them or they are replaced.

Multi-select

Use the Select tool to drag a box around multiple objects. When objects are selected:

  • A combined Object Config panel shows shared properties (e.g. color if all selected objects share a color, opacity, spin direction for saw blades, etc.).
  • The Rotate, Duplicate, Erase, and Move actions apply to the whole selection.
  • Use Save Stamp to store the selected objects as a reusable Object Stamp for this map.
  • Click an empty area to deselect.

Object Stamps

Object Stamps save a group of up to 64 selected map objects. Choose Add → Object Stamp, pick a saved stamp, then click the map to place a copy. Each placed object receives a new ID, and portal connections between portals in the copied group are remapped together. A map can store up to 32 stamps; stamps stay with that map and survive save/load and .pkrn export/import. Use Export to download one stamp as a portable .pkrstamp file, then choose Import in another map's stamp picker to reuse it. Version 1 files contain data only, hold at most 64 objects, and are limited to 2 MiB; malformed object data is rejected. The format is described by the Object Stamp schema. Import renames a stamp when its name already exists in the map. Mechanics blocks and links to objects outside the copied group are not included.

A stamp copies object settings and layout. It does not copy mechanics triggers or events, or references in mechanics that target the original objects by ID.

Animated object artwork

Open an object’s settings and add a PNG, JPEG, or WebP sprite sheet (up to 1 MB per image). Set the frame width and height, number of frames, and playback speed. Frames are read left to right and then top to bottom; the image replaces the object’s artwork while its collision and mechanics behavior stay in place. Objects moved by Mechanics face left or right based on their current horizontal movement. Sprite sheets are saved with the map, packaged as media files in .pkrn exports, and included in portable Object Stamps. Map objects support up to 256 frames at 1–30 FPS, with 8 MiB total sprite data per map.

Tilemap Brush

Choose Add → Tilemap Brush to paint 32×32 px cells. Pick a draw layer, surface texture, color, opacity, cell behavior, and collision shape. For solid or one-way cells you can choose a validated convex polygon with 3–12 normalized vertices; one-way cells can use a top-surface polygon, while solid cells can use one-way or fully solid polygon collision. Tile artwork remains independent from collision geometry. Enable Show Touchboxes during Test to inspect the polygon boundary. Choose a cell behavior: Solid, One-way platform, Ramp rising to the right, Ramp rising to the left, Damage on touch, or Decorative. Built-in surfaces include solid fill, brick, stone, wood, and moss; the tint and opacity controls apply to textured cells too. To use custom art, upload a PNG, JPEG, or WebP tile atlas up to 1 MiB, set its frame dimensions, choose a zero-based frame in row-major order, then paint. Each frame is scaled to a 32×32 cell; collision stays controlled by the cell behavior. Atlas image data is limited to 8 MiB and 32 megapixels across a map; use Clear atlas to return a layer to its built-in textures. Atlas data is saved with maps and `.pkrn` media files. Texture cycle animates two to eight built-in surface texture frames, while Atlas frame cycle animates two to eight selected atlas frames, each at 1–12 frames per second. Animated cells keep the same collision behavior and are limited to 2,048 per map. One-way cells have a gold top cue, ramps show their slope, and damage cells show a warning mark. Drag to paint a stroke; use the Erase tool to remove tilemap cells. Cells are stored as compact tilemap data instead of separate map objects. Tilemaps and animation settings are included in save/load and .pkrn import/export.

Mechanics can use Player Touches Tilemap to run an event when a player enters collidable cells on a selected tilemap, optionally filtered to solid, one-way (including either ramp), or damage cells. The Set Tilemap Cell Behavior event action changes a fixed cell or the cell touched by the event to solid, one-way, either ramp direction, damage, or decorative for the current play session. Set Tilemap Cell Enabled can remove an authored cell to open a passage or restore it later; cell artwork and collision come back together. Reset restores the authored map. Large-map streaming remains future work.

Object inspector

Click any placed object to open its Object Inspector — shows all per-object config settings. For multi-selected objects, shared settings are shown and edited collectively.
