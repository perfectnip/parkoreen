🏁 Checkpoint

Respawn markers with heal option and checkpoint sound in v0.4.

Overview

Checkpoints save the player's respawn position. In v0.4, touching an active checkpoint plays a checkpoint sound. The heal-at-checkpoint option (from v0.3) is retained.
