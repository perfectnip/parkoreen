⚙️ Map Config

All map-level settings available in this build of Parkoreen.

General

  • Map NameUntitledDisplay name for the map.
  • Author(empty)Creator credit shown on the map screen.
  • Backgroundskysky — daytime clouds. galaxy — space backdrop with purple clouds. The editor also includes Misty Mountains, Pine Forest, Quiet Coast, Desert Dunes, and Twilight Ruins, plus custom uploaded backgrounds.

Physics

  • Gravity0.71Downward acceleration applied each tick. Higher = heavier feel.
  • Terminal Fall SpeedGravity-scaled (16 at default gravity)Optional maximum downward speed from 1 to 100 pixels per tick. Older maps keep a gravity-scaled limit unless you set an explicit value.
  • Jump Force-13.2Vertical velocity on jump (negative = upward). More negative = higher jump.
  • Player Speed5Horizontal movement speed in pixels per tick.
  • Horizontal Acceleration0 (instant)Acceleration and braking in pixels per tick squared, from 0 to 20. Zero preserves legacy instant-start, instant-stop movement.
  • Air Control1Scales horizontal acceleration while airborne from 0 (keep momentum) to 1 (full control). It applies when Horizontal Acceleration is above zero.
  • Max Jumps1How many times the player can jump before landing.
  • Infinite JumpsOffIf on, jump count is never exhausted.
  • Additional Air JumpOffGrants an extra mid-air jump (double-jump).
  • Die Line Y1000Y position (px) at which the player instantly dies if they fall below it.

Camera

  • Follow ModeBoth axesFollow the player on both axes, horizontally only (useful for side-scrollers), or vertically only (useful for climbing rooms).
  • Horizontal / Vertical Smoothness0.12 / 0.12Controls how quickly the gameplay camera follows the player on each axis.
  • Camera BoundsOffWhen enabled, clamps the gameplay and test camera to the configured world-space rectangle (left X, top Y, width, height). If the rectangle is smaller than the visible viewport, the camera centers it. Editor navigation remains free.

Spike settings

  • Spike TouchboxnormalGlobal hitbox mode: normal, full, tip, ground, flag, air, all-spike.
  • Drop Hurt OnlyOffSpikes only kill when the player is falling onto them.

Default colors

  • Block Color#787878Default color for new blocks.
  • Spike Color#c45a3fDefault color for new spikes.
  • Text Color#000000Default color for new text objects.
  • Portal Color#9b59b6Default color for new teleportals.
  • Bouncer Color#461A0CDefault color for new bouncers.

Coin settings

  • Show Coin CounterOnDisplays the coin counter HUD during gameplay when coins are present on the map.

Checkpoint colors

  • Inactive Color#808080Untouched checkpoint color.
  • Touched Color#2196F3Previously-passed checkpoint color.
  • Active Color#4CAF50Color used for the checkpoint currently selected as the respawn point.
  • Remember Latest CheckpointOffWhen enabled, saves the player's latest checkpoint locally and starts future play sessions there. The save stays in this browser under the current account, or the browser device when signed out; it does not sync between devices. Test runs do not change saved progress.

Cloud colors

  • Cloud Color (Sky)#ffffffCloud tint when background is sky.
  • Cloud Color (Galaxy)#9382a8Cloud tint when background is galaxy.
