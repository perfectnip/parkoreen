Parkoreen on your device

Install Parkoreen as a web app for a home-screen or desktop shortcut and a focused, app-like window. It’s the same game on every device, and it updates from the web whenever you’re online.

Play in browser

Choose your device below for installation steps.

phone_androidAndroid

  1. Open this page in Chrome.
  2. Tap Install Parkoreen above, or open the ⋮ menu and choose Install app (sometimes shown as Add to Home screen).
  3. Open Parkoreen from your home screen or app list.

The Android version is an installable web app, not a separate APK. Chrome updates it from the website; keep a connection to receive the newest game version.

Android web app install help

desktop_windowsWindows

  1. Open this page in Chrome or Edge.
  2. Select the install icon in the address bar, or use the browser menu’s Install Parkoreen option.
  3. Launch it from the Start menu or taskbar.

The installed app uses the same online game and updates through the browser.

Chrome web app install help

laptop_macmacOS

  1. In Safari, open this page.
  2. Choose Share → Add to Dock. You can also install from Chrome’s address bar or app menu.
  3. Open Parkoreen from the Dock or Applications.

Safari web apps use the current Parkoreen website and receive its updates while online.

computerLinux

  1. Open this page in Chrome or Chromium.
  2. Select the install icon in the address bar, or open the browser menu and choose Install Parkoreen.
  3. Launch it from your desktop’s application list.

On browsers without web app installation, bookmark Parkoreen or create a browser shortcut.

laptop_chromebookChromebook

  1. Open this page in Chrome.
  2. Click the install icon in the address bar, or choose Save and share → Install page as app.
  3. Launch Parkoreen from the Chromebook Launcher.

This is the web app version and works on Chromebooks that can access the Parkoreen site.

ChromeOS web app install help

Updates and offline use

Parkoreen checks for new web assets when you open the game and updates its local app cache automatically. No separate installer or manual update download is needed. Online access is still required for accounts, Community, multiplayer, and other server features; cached screens may open offline with limited functionality.

For the best experience, use a current version of Chrome, Edge, Safari, or Chromium. Installation options depend on your browser and device settings.
